# Fiador brand: the Seat mark

One block is the DAO treasury. The single red corner seat is the one seat the desk holds in the DAO's policy.

## Colors

These are the product's own tokens, the same ones the board and the landing page use.

| Name | Hex | Where |
|---|---|---|
| Ink | `#1f1a15` | the block and the wordmark |
| Oxblood | `#7b1e2c` | the seat |
| Paper | `#faf8f3` | the background; the block and the wordmark when reversed |
| Reversed accent | `#d4707c` | the seat on dark backgrounds |

## Size

- The mark: no smaller than **16 px**.
- The lockup: no narrower than **96 px**.

## Clear space

Keep empty space on all four sides equal to the width of the red seat. In the mark that's 22 of 64 units, about a
third of the mark's width (22 px around a 64 px mark). In the lockup, the seat is drawn at three quarters scale,
so it's 16.5 px at the lockup's native 266 px width.

## Do

- Use the color mark or lockup on paper or another light background.
- Use the reversed versions on dark backgrounds.
- Use the mono versions only when one ink is all you have.
- Scale proportionally, from the SVG whenever you can.

## Don't

- Don't add gradients, shadows or outlines.
- Don't recolor any part, or swap the seat's color for anything but the reversed accent on dark.
- Don't stretch, squash, rotate or crop it.
- Don't move the seat, change its size, or close the gap between the seat and the block.
- Don't put the color mark on a dark background.
